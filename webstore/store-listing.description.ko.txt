EvidenceShot은 지금 보고 있는 페이지를 증빙용 스크린샷으로 빠르게 저장하는 Chrome 확장 프로그램입니다. 테스트 기록이나 작업 증빙을 남길 때 사용할 수 있습니다.

특징
- 팝업의 버튼 또는 단축키(기본값은 Ctrl+Shift+Y, Mac은 Command+Shift+Y)로 바로 캡처
- 캡처 범위는 "표시 영역만(1화면)", "전체 페이지(레이아웃 포함)"(좌우 칼럼 포함), "본문만"(중앙 주 칼럼) 중에서 선택
- 전체 페이지와 본문만 캡처는 스크롤하면서 세로로 이어 붙여 1장으로 저장
- PNG / JPEG / WEBP로 저장
- 캡처한 날짜와 시간을 이미지 오른쪽 아래에 새겨 넣습니다. 타임스탬프 스타일은 공문서, 붉은 인장, 회계 장부, 청사진, 터미널, 네온사인 등 15종이며 글자 크기는 5단계 중에서 선택할 수 있고, 시간대(+09:00 등)를 넣을지도 전환할 수 있습니다
- 왼쪽 아래에 임의의 고정 텍스트(예: 대외비, 회사명)를 넣을 수 있으며, 날짜와 같은 스타일과 글자 크기로 표시됩니다
- 새겨 넣을 모양을 팝업에서 미리 보기
- 파일 이름 접두사를 지정할 수 있습니다(비워 두면 사이트 이름으로 자동 지정되며, 날짜와 시간은 자동으로 추가됩니다)
- 캡처 후 이미지를 클립보드에도 복사하여 Excel 등에 그대로 붙여넣기 가능
- PNG로 저장하면 캡처한 페이지의 URL(쿼리와 해시 제외), 시간, 제목과 이미지 데이터의 해시(SHA-256)를 이미지 안에 기록합니다. 이미지가 편집되거나 다시 저장되지 않았는지 확인하는 단서가 됩니다(전자 서명은 아닙니다)
- 일본어 글꼴을 내장하여 캡처 이미지와 팝업을 같은 글자 모양으로 표시
- 팝업은 브라우저 테마에 맞춰 라이트 / 다크를 자동으로 전환
- 팝업에서 Kagayoi Support로 문의할 수 있습니다
- 저장 위치는 브라우저의 기본 다운로드 폴더입니다

사용 방법
1. 도구 모음의 확장 프로그램 아이콘을 누릅니다
2. 팝업에서 캡처 범위, 저장 형식, 날짜 등을 확인합니다
3. "이 탭 캡처"를 누르거나 단축키를 사용합니다

참고
- 스크롤 이어 붙이기 캡처는 캡처를 시작한 시점의 페이지 끝까지가 대상입니다. 캡처 중에 새로 불러온 부분은 포함하지 않으므로 무한 스크롤 페이지에서도 끝 위치가 흔들리지 않습니다
- 긴 페이지는 이미지 크기 제한에 맞춰 여러 파일로 나누어 저장하며, 파일 이름에 "-part1-of2"와 같은 번호를 붙입니다. 나누어 저장했을 때는 클립보드 복사를 생략합니다
- 스크롤 스냅 등으로 예정된 위치로 이동하지 못한 경우에는 부정확한 이미지를 저장하지 않고 캡처를 중단합니다. 이 경우에는 "표시 영역만(1화면)"을 사용하세요
- Chrome 웹 스토어처럼 브라우저가 확장 프로그램의 동작을 금지하는 페이지는 캡처할 수 없습니다
- 단축키의 실제 할당은 팝업의 "단축키 설정"에서 확인하고 변경할 수 있습니다

권한 및 데이터 처리
- 모든 사이트에 상시 접근하는 권한은 사용하지 않습니다. 캡처는 사용자가 조작했을 때 현재 탭에 대해서만 수행합니다
- 캡처한 이미지는 기기의 다운로드 폴더에 저장할 뿐 외부로 전송하지 않습니다
- 문의 양식을 제출했을 때만 입력한 내용을 Kagayoi Support로 전송합니다
